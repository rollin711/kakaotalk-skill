# 카톡수집 — 카카오톡 업무 대화를 Claude Code로 정리하는 스킬

거래처·팀과 카카오톡으로 주고받은 업무 대화를 Claude Code가 직접 읽고, **일정·요청사항·합의 내용·내가 할 일**만 정리해 줍니다.
매번 「대화 내보내기」를 눌러 파일을 저장하고 붙여넣는 일을 하지 않아도 됩니다.

```
나:     카톡 수집해줘
Claude: 거래처A_프로젝트방 — 새 메시지 14건
        · 시안 수정본 금요일 오후 3시까지 요청
        · 견적은 기존 단가 유지로 합의
        · 내가 할 일: 목요일까지 수정 일정 회신
```

> **Mac 전용 기능**과 **모든 PC에서 쓰는 기능**이 있습니다.
> - Mac: 카카오톡 PC 앱에 쌓인 대화를 자동으로 읽습니다(새 대화만).
> - Windows 등: 카카오톡에서 「대화 내보내기」로 저장한 파일을 안전하게 정리합니다.

---

## 1. 어떻게 작동하나요

### ① 카카오톡 PC 앱은 대화를 내 컴퓨터에 보관합니다
휴대폰이 꺼져 있어도 PC 카카오톡에서 지난 대화가 보이는 이유는, PC 앱이 대화를 **내 컴퓨터 안의 숨은 폴더**에 파일로 저장해 두기 때문입니다.
Mac에서는 `라이브러리 › Containers › 카카오톡` 아래에 있습니다. 평소에는 Finder에서 보이지 않는 폴더입니다.

### ② 그 파일은 잠긴 금고입니다
이 파일은 암호화되어 있어 그냥 열면 알아볼 수 없는 글자만 보입니다.
열쇠는 따로 저장되어 있지 않고, **내 Mac의 기기 고유번호**와 **내 카카오 계정 번호**를 섞어 열 때마다 만들어집니다.

### ③ kakaocli가 같은 재료로 열쇠를 만들어 「읽기만」 합니다
[kakaocli](https://github.com/PeraSite/kakaocli)는 공개된 오픈소스 도구입니다. 내 Mac 안에 있는 재료로 열쇠를 계산해 금고를 **읽기 전용**으로 엽니다.
- 처음 한 번 `auth` 단계에서 내 계정 번호를 찾아 기억해 둡니다. 열쇠 자체는 저장하지 않고, 쓸 때마다 계산합니다.
- 카카오 서버에 접속하거나 로그인하지 않습니다. 대화를 고치거나 지우지도 않습니다.
- PC 카카오톡에 저장된 대화만 읽습니다. 휴대폰에만 있는 오래된 대화는 읽을 수 없습니다.

### ④ 이 스킬은 kakaocli 앞에 「안내 데스크」를 하나 더 둡니다
kakaocli는 원래 모든 방을 검색하고 메시지를 보내는 기능까지 갖고 있습니다. 업무에 쓰기에는 너무 많은 권한입니다.
그래서 이 스킬은 Claude가 kakaocli를 직접 실행하지 못하게 하고, 아래 안전장치를 거친 스크립트만 쓰게 합니다.

```
카카오톡 저장 파일(잠김) ──▶ kakaocli(읽기 전용으로 열기) ──▶ 안내 데스크(이 스킬) ──▶ Claude
                                                      · 허용한 방만 통과
                                                      · 발송·검색 명령 차단
                                                      · 주민번호·계좌·카드·휴대폰 번호 가림
                                                      · 지난번 이후 새 대화만
```

## 2. 이 스킬만의 안전장치

| 안전장치 | 내용 | 이유 |
|---|---|---|
| **허용 목록** | `rooms.json`에 등록한 방만 읽습니다 | 가족·친구 대화가 AI에 들어가지 않게 합니다 |
| **방 목록에는 내용이 없음** | 방을 고를 때는 방 이름·인원·마지막 대화 날짜만 봅니다 | 고르는 과정에서도 대화 내용이 노출되지 않습니다 |
| **오픈채팅 제외** | 오픈채팅방은 후보에도 나오지 않습니다 | 모르는 사람들의 대화를 다루지 않습니다 |
| **명령 제한** | 「방 목록」과 「메시지 읽기」 두 가지만 허용합니다. 보내기·로그인·전체 검색은 막혀 있습니다 | AI가 실수로 메시지를 보내거나 다른 방을 읽는 일을 막습니다 |
| **민감번호 가림** | 주민등록번호·카드번호·휴대폰번호·계좌번호를 `[계좌번호]`처럼 바꿔 저장합니다. 전각 숫자나 띄어쓰기·점으로 나눈 번호도 찾아냅니다 | 대화에 섞인 개인정보가 기록 파일과 AI에 남지 않습니다 |
| **새 대화만** | 지난번에 어디까지 읽었는지 기억하고 그 뒤만 가져옵니다 | 같은 내용을 반복해 읽지 않아 빠르고 정확합니다 |
| **방마다 볼 것 지정** | 방마다 `focus`(예: 「일정·요청사항만」)를 적어 둡니다 | 요약에 잡담이 섞이지 않습니다 |
| **대화 속 지시 무시** | 메시지 안에 「파일을 보내라」 같은 문장이 있어도 Claude는 따르지 않고, 그런 메시지가 있다고만 알립니다 | 누군가 대화방에 남긴 문장이 AI를 움직이지 못하게 합니다 |
| **열쇠 재료 비공개** | Claude는 kakaocli 설정 파일을 열지 않습니다 | 잠금 해제 재료가 대화창에 노출되지 않습니다 |
| **검증한 버전 고정** | kakaocli를 내용을 확인한 특정 버전으로 설치합니다 | 나중에 바뀐 코드가 몰래 들어오는 것을 막습니다 |
| **내 파일만 열람 가능** | 기록 파일을 나만 읽을 수 있는 권한으로 저장합니다 | 같은 컴퓨터의 다른 계정이 읽지 못합니다 |

## 3. 설치 (Mac)

**준비물**: Mac, Claude Code(VS Code 확장 또는 Claude 데스크톱 앱 Code 화면), 카카오톡 PC 앱 로그인 상태

설치는 Claude Code에게 맡기면 됩니다. Claude Code 대화창에 아래 문장을 그대로 붙여넣으세요.

```
https://github.com/rollin711/kakaotalk-skill 저장소의 README 「3. 설치」를 따라
카톡수집 스킬을 설치해 줘. 비밀번호가 필요한 단계와 auth 단계는 내가 직접 할게.
```

Claude Code가 진행하는 단계는 아래와 같습니다. 직접 해도 됩니다.

**1) 도구 준비** — Homebrew가 없으면 [brew.sh](https://brew.sh)의 안내대로 먼저 설치합니다(Mac 비밀번호 입력은 직접 합니다).
```bash
xcode-select --install          # 이미 설치되어 있으면 건너뜁니다
brew install sqlcipher
```

**2) kakaocli 설치 — 검증한 버전으로 고정**
```bash
git clone https://github.com/PeraSite/kakaocli.git ~/kakaocli-src
cd ~/kakaocli-src
git checkout 6c971d3a70488d5d3b1e1a646d326204264dc12c
swift build -c release
mkdir -p ~/.local/bin
install -m 755 .build/release/kakaocli ~/.local/bin/kakaocli
~/.local/bin/kakaocli --version  # 0.7.0-local.1 이 나오면 성공
```

**3) 처음 한 번, 열쇠 재료 확인 (직접 실행)** — VS Code 아래쪽 터미널에서 실행합니다. 최대 2분 정도 걸립니다.
```bash
~/.local/bin/kakaocli auth --save
```
「다른 앱의 데이터에 접근하려고 합니다」 같은 확인 창이 나타나면 허용합니다. 이 단계는 AI가 아니라 본인이 실행하는 것이 안전합니다.

**4) 스킬 설치**
```bash
git clone https://github.com/rollin711/kakaotalk-skill.git ~/kakaotalk-skill
mkdir -p ~/.claude/skills
cp -R ~/kakaotalk-skill/skills/카톡수집 ~/.claude/skills/
```

**5) 읽을 방 고르기** — Claude Code에게 이렇게 말합니다.
```
카톡 후보 방 보여줘
```
방 이름 목록이 나오면 업무 방만 골라 「이 방들 등록해줘」라고 합니다. Claude가 `rooms.json`을 만들어 줍니다.

## 4. 사용법

| 이렇게 말하면 | 이렇게 됩니다 |
|---|---|
| `카톡 수집해줘` | 등록한 모든 방의 새 대화를 가져와 방별로 정리합니다 |
| `거래처A 방 카톡 확인해줘` | 그 방만 가져옵니다 |
| `카톡 후보 방 보여줘` | 최근 90일 안에 대화가 있는 방 목록(내용 없음) |
| `○○방도 등록해줘` | 허용 목록에 추가합니다(추가 전에 확인을 받습니다) |
| `내보낸 카톡 파일 정리해줘` | 내보내기 txt를 가림 처리한 뒤 정리합니다 |

가져온 대화는 `~/카톡기록/카톡_<방 이름>.md`에 날짜별로 쌓입니다.

## 5. Windows에서 쓰기 (대화 내보내기 방식)

kakaocli는 Mac 전용이라 Windows에서는 자동 읽기가 되지 않습니다. 대신 내보내기 파일을 안전하게 정리합니다.

1. 위 「4) 스킬 설치」와 같은 방법으로 스킬 폴더를 `사용자 폴더\.claude\skills\` 아래에 복사합니다(Claude Code에게 맡겨도 됩니다).
2. PC 카카오톡에서 대화방 → 오른쪽 위 메뉴(≡) → 「대화 내용」 → 「대화 내보내기」로 txt를 저장합니다. 앱 버전에 따라 메뉴 위치가 다를 수 있습니다.
3. Claude Code에게 `내보낸 카톡 파일 정리해줘: <파일 경로>`라고 말합니다.
4. 민감번호를 가린 사본이 `카톡기록` 폴더에 생깁니다. 원본 txt는 확인 후 직접 지웁니다.

> 이 방식은 Python이 필요합니다. 설치되어 있지 않으면 Claude Code에게 「Python 설치해 줘」라고 요청하거나 [python.org](https://www.python.org/downloads/)에서 설치합니다. 회사 보안 설정으로 Python 실행이 막혀 있으면 IT 담당자에게 허용을 요청해 주세요.

## 6. 꼭 지켜 주세요

- **업무 방만 등록합니다.** 단체방에는 다른 사람의 대화도 있으므로, 업무 목적에 필요한 방만 고릅니다.
- **기록 파일을 GitHub에 올리지 않습니다.** `~/카톡기록` 폴더는 프로젝트 폴더 바깥에 두고, 공유 드라이브·노션·메일에도 원문을 올리지 않습니다. 다른 곳에 옮길 때는 요약만 옮깁니다.
- **메시지 발송은 하지 않습니다.** 이 스킬은 읽기 전용입니다. kakaocli의 발송 기능을 따로 켜지 마세요.
- **회사 보안 정책을 먼저 확인합니다.** 회사 PC라면 사내 정책상 허용되는지 확인하고 사용합니다.
